# University Analytics Project Demo

This project demonstrates how to package EDA and preprocessing work into a small, shareable Python project.

It builds on EDA and data preprocessing work done in previous weeks, and adds a simple end-to-end project structure.:

- 1: exploratory data analysis and data quality checks
- 2: preprocessing, joins, feature thinking and leakage awareness
- 3: end-to-end project thinking and preparing work for review

## Project structure

- `src/`: Python code
- `sql/`: saved SQL queries
- `reports/`: generated report outputs

## How to use this project

1. Create a virtual environment.
2. Install the recorded dependencies.
3. Create or connect to the local practice database.
4. Run the Python report.
