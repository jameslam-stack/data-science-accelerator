Converting string dates to datetime

Step 1 of 6 • Data preparation

Time series data requires date strings to be converted into datetime64 format using pd.to_datetime().

Show code example and hint ▼ 
# Convert text column to pandas datetime
auckland['date'] = pd.to_datetime(auckland['Date'])
auckland.dtypes

Key take-away: Always verify that your date column displays datetime64[ns].

2

Setting and sorting the datetime index

Step 2 of 6 • Indexing

Setting the datetime column as your DataFrame index enables date-based slicing. Always sort the index chronologically using .sort_index().

Show code example and hint ▼ 
# Set date column as index and sort chronologically
auckland = auckland.set_index('date')
auckland.sort_index(ascending=True, inplace=True)

Key take-away: A sorted datetime index is required for date filtering and resampling.

3

Slicing and filtering time series data

Step 3 of 6 • Selection

Filter specific years or date ranges easily using string indexing with .loc[], or filter days of the week using .index.day_name().

Show code example and hint ▼ 
# Slice single year 2000
auckland.loc['2000'].plot()

# Slice date range 2000 to 2005
auckland.loc['2000':'2005'].plot()

# Filter for Mondays
auckland[auckland.index.day_name() == 'Monday'].plot()

Key take-away: String date slicing is intuitive and fast in pandas.

4

Handling outliers and missing values

Step 4 of 6 • Cleaning

Identify outliers using .describe(). Replace erroneous entries with np.nan, enforce explicit dates with .asfreq('D'), and fill gaps with forward fill (.fillna(method='ffill')).

Show code example and hint ▼ 
# Enforce daily frequency and forward fill missing values
auckland = auckland.asfreq('D')
auckland = auckland.fillna(method='ffill')

Key take-away: Always choose an imputation technique suitable for your dataset.

5

Resampling and changing data frequency

Step 5 of 6 • Resampling

Change the frequency of your time series using .resample(). For example, downsample daily data to yearly averages using .resample('Y').mean().

Show code example and hint ▼ 
# Resample daily series into yearly mean values
yearly_avg = auckland.resample('Y').mean()
yearly_avg.plot()

Key take-away: Resampling requires chaining an aggregation function like .mean().

6

Rolling window averages and smoothing

Step 6 of 6 • Smoothing

Reduce noise and highlight long-term trends by calculating moving window averages using .rolling(window=N).mean().

Show code example and hint ▼ 
# Apply 365-day rolling average to smooth daily noise
auckland.rolling(window=365).mean().plot()

Key take-away: Rolling averages maintain original data resolution while smoothing short-term noise.
